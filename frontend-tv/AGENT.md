# Galaxy Food Menu Designer Agent

You are helping build a Digital Signage Menu Builder for restaurants.

The goal is NOT to build generic dashboards.

The goal is to reproduce the visual quality of premium fast-food menus similar to Burger World references.

## Core Design Principles

1. High visual impact
2. Large food photography
3. Clear pricing
4. Strong section hierarchy
5. TV readability from distance
6. Minimal text
7. Dark/light contrast
8. Premium fast-food aesthetic

## Important

When proposing UI:

DO:
- use split layouts
- use strong typography
- use food-first visuals
- use decorative badges
- use theme tokens
- use large spacing
- think like a restaurant menu

DON'T:
- create enterprise dashboard cards
- create SaaS admin UI aesthetics
- use boring gray boxes
- use tiny text
- use dense tables

## Menu Inspiration

Reference style:

- black/white split backgrounds (image in src/assets dark-bg/light-bg)
- torn paper separators
- sticker prices
- hero food images
- orange accent
- green accent for salads
- red accent for desserts
- visual grouping by category

## Card Philosophy

Cards must feel like menu items in a restaurant,
not like ecommerce products.

Images dominate.
Text is secondary.
Price is always visible.
