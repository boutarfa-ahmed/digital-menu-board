# Visual Language

## Colors

Primary:
#FF6B00

Dark:
#121212

Light:
#F5F5F5

Success:
#4CAF50

Dessert:
#E53935

## Layout Rules

Maximum 2 dominant colors per screen.

Each screen should contain:

- one visual anchor
- one section title
- clear pricing hierarchy

## Torn Paper

Use torn paper effect:

- center divider
- section headers
- badge backgrounds

Never overuse.

## Product Images

Images should occupy:

50-70% of card area

Text should occupy:

30-50%

## Prices

Price badges should be:

- high contrast
- detached from body
- visually elevated

Examples:

- torn paper
- stamp
- ribbon

## Typography

Heading:
Anton / Bebas Neue

Body:
Inter

Price:
Bold condensed
